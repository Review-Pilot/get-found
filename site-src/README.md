# Get Found website source

The live site is the `public/` folder, served by Cloudflare (see `wrangler.jsonc`)
and deployed automatically from `main` by `.github/workflows/deploy.yml`.

Most pages are generated, so shared things (header, footer, FAQs, pricing, blog
layout) stay consistent. To change copy or add a page:

1. Edit `site-src/content.py` (contact details, pricing, FAQs, reviews) or
   `site-src/build.py` (page layouts and copy), or `site-src/posts.json` (blog posts).
2. Run `python3 site-src/build.py` (Python 3.9+, no extra packages needed).
3. Commit the changed files in `public/` and `site-src/`.

Styles live in `public/assets/css/style.css`, scripts in `public/assets/js/main.js`.
Old Wix URLs are redirected in `public/_redirects` (generated by the build).
